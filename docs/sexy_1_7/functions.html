Functions and primitive types

A function has named inputs and named outputs. There is no return statement for values: you assign to the outputs, and they start at zero.

A first function

The signature lists inputs, then ->, then outputs, then a colon and the body. A function with one output can be used as a value, as (Square 7) is here.

Sexy
(namespace EntryPoint)
(alias Main EntryPoint.Main)

(function Square (Int32 x) -> (Int32 y):
    (y = (x * x))
)

(function Main -> (Int32 result):
    (result = (Square 7))
)
Python 3
def square(x: int) -> int:
    return x * x

def main() -> int:
    return square(7)

assert main() == 49

Result Main returns 49

Several outputs

Outputs are ordinary variables of the callee. The caller receives them after a second ->, into variables it has already declared. Every input and output carries a type; there are no tuples to unpack.

Sexy
(function DivRem (Int32 a)(Int32 b)
    -> (Int32 quotient)(Int32 remainder):
    (quotient = (a / b))
    (remainder = (a - (quotient * b)))
)

(function Main -> (Int32 result):
    (Int32 q)
    (Int32 r)
    (DivRem 17 5 -> q r)
    (result = ((q * 10) + r))
)
C++20
#include <cassert>

struct DivRemResult { int quotient; int remainder; };

DivRemResult DivRem(int a, int b)
{
    int q = a / b;
    return { q, a - q * b };
}

int main()
{
    auto [q, r] = DivRem(17, 5);
    assert(q * 10 + r == 32);
}

Result Main returns 32

Default arguments

A default is an attribute on the parameter. The caller must still write the argument position, using . to mean "the default", so a call always shows how many arguments the function takes.

Sexy
(function Add (Int32 a)(Int32 b (attribute default 7))
    -> (Int32 sum):
    (sum = a + b)
)

(function Main -> (Int32 result):
    (result = (Add 4 .))
)
C++20
#include <cassert>

int Add(int a, int b = 7) { return a + b; }

int main()
{
    assert(Add(4) == 11);   // Sexy needs (Add 4 .)
}

Result Main returns 11

Primitive types and literals

The built-in value types are Int32, Int64, Float32, Float64 and Bool. A literal has no suffix; it takes the type of whatever it is assigned to, so 1 is a valid Float64. A declared variable without a value starts at zero.

Sexy
(function Main -> (Int32 result):
    (Int32 count = 3)
    (Int64 big = 0x100000000)
    (Float32 half = 0.5)
    (Float64 ratio = 1)       // the literal 1 takes the type of the target
    (Bool ready = true)
    (Int32 zero)              // locals start at zero
    (if ready (result = count + zero))
)

Result Main returns 3

No implicit conversion

Literals adapt, but variables do not. Assigning an Int32 variable to a Float32 is an error. Convert explicitly with the Sys.Maths functions, for example Sys.Maths.F32.ToInt32, which truncates.

Sexy
(function Main -> (Int32 result):
    (Int32 count = 3)
    (Float32 f = count)
)
C++20
#include <cassert>

int main()
{
    int count = 3;
    float f = count;        // compiles: implicit int -> float (-Wconversion warns at best)
    double ratio = 1;       // also fine
    assert(f == 3.0f && ratio == 1.0);
    int truncated = static_cast<int>(3.75f);   // explicit, as with Sys.Maths.F32.ToInt32
    assert(truncated == 3);
}

Error The type Float32 of f does not match the type Int32 of count

Sexy
(function Main -> (Int32 result):
    (Float32 f = 3.75)
    (result = (Sys.Maths.F32.ToInt32 f))
)

Result Main returns 3

Bodies compile on first call

The host compiles every declaration before running anything, but a function body is compiled to bytecode the first time it is called. A type error in a body that never runs is never reported. In that respect Sexy behaves more like Python than C++, despite the static types.

Sexy
(function NeverCalled -> (Int32 y):
    (Int32 count = 3)
    (Float32 f = count)    // type error, but this body is never compiled
)

(function Main -> (Int32 result):
    (result = 1)
)
Python 3
def never_called() -> int:
    count = 3
    return count + "three"   # TypeError, but only if this line ever runs

def main() -> int:
    return 1

assert main() == 1

Result Main returns 1

Test every function you ship. A clean compile of the script only means the declarations are valid.

Loops

for takes three compounds: the declaration, the condition and the step. while has break and continue. The compound assignments are +=, -=, *= and /=.

Sexy
(function Factorial (Int32 n) -> (Int32 f):
    (f = 1)
    (for (Int32 i = 2)(i <= n)(i += 1)
        (f *= i)
    )
)

(function Main -> (Int32 result):
    (result = (Factorial 5))
)

Result Main returns 120

Sexy
(function Main -> (Int32 result):
    (Int32 i = 0)
    (while (i < 10)
        (i += 1)
        (if (i == 5) (continue))
        (if (i > 7) (break))
        (result += i)
    )
)
Lua 5.4
local result = 0
local i = 0
while i < 10 do
  i = i + 1
  if i == 5 then goto continue end   -- Lua has no continue statement
  if i > 7 then break end
  result = result + i
  ::continue::
end
assert(result == 23)

Result Main returns 23

Recursion

A function can call itself, and functions can be declared in any order.

Sexy
(function Main -> (Int32 result):
    (result = (Fib 10))               // Fib is declared below
)

(function Fib (Int32 n) -> (Int32 f):
    (if (n < 2)
        (f = n)
    else
        (f = (Fib (n - 1)) + (Fib (n - 2)))
    )
)

Result Main returns 55

Operators have no precedence

A compound with more than one operator is grouped from the right: (a op b op c) means (a op (b op c)). Chains of + come out as you would expect, but mixed or non-associative chains do not. Parenthesise anything other than a plain sum.

Sexy
(function Main -> (Int32 result):
    (result = 10 - 3 - 2)    // parsed as 10 - (3 - 2)
)
Python 3
result = 10 - 3 - 2      # left-associative: (10 - 3) - 2
assert result == 5
result = 10 - (3 - 2)    # what Sexy computes for (10 - 3 - 2)
assert result == 9

Result Main returns 9
