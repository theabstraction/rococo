Sexy 1.7

Sexy is the scripting language of the Rococo engine. It is statically typed, written as s-expressions, compiled to bytecode for the Sexy virtual machine, and embedded in a C++ host.

These pages describe the language as it is on the 1.7 development branch. They are written for people who already know C++ and want to know how Sexy differs. Every Sexy example was compiled and run through the test harness, and the result or error message shown under it is the real one. The comparison code next to it is in whichever of Python, Lua or C++ makes the difference clearest. It was run too.

SyntaxEverything is an s-expression: (function Square (Int32 x) -> (Int32 y): (y = (x * x))). Operators are infix inside a compound, with no precedence.
TypesStatic and strict. Int32, Int64, Float32, Float64, Bool, structs (values), interfaces (references), strong types and enums. Variables never convert implicitly; literals take the type of their target.
CompilationThe host compiles declarations up front. Function bodies are compiled to bytecode the first time they are called, so an error inside a body appears when the script runs.
ObjectsClasses are used through interfaces and created by factories. Objects are reference counted, so a destructor runs as soon as the last reference goes, not at some later collection.
HostThe C++ program creates a script system, adds native functions and sources, compiles, and runs EntryPoint.Main on the VM.

About the examples

Each Sexy example is a complete program whose Main returns an Int32 to the host. The host looks for EntryPoint.Main, so every program also contains these two lines, which the pages omit after the first example:

Sexy
(namespace EntryPoint)
(alias Main EntryPoint.Main)
