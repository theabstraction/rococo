Structs

A struct is a value type with public members. Structs are copied on assignment but passed to functions by reference, and their operators are ordinary functions found by name.

Declaration and memberwise initialisation

Members of the same type can share one declaration, as x and y do. A struct variable is initialised by listing values in member order; nested structs take a parenthesised group each. Assignment copies.

Sexy
(struct Vec2i (Int32 x y))
(struct Recti (Vec2i topLeft)(Vec2i bottomRight))

(function Main -> (Int32 result):
    (Vec2i p = 3 4)
    (Recti r = (0 0)(640 480))
    (Vec2i q = p)                     // copy
    (q.x = 100)
    (result = r.bottomRight.y + (q.x * 6) + p.x + p.y + (r.topLeft.x * 7))
)
C++20
#include <cassert>

struct Vec2i { int x, y; };
struct Recti { Vec2i topLeft, bottomRight; };

int main()
{
    Vec2i p = { 3, 4 };
    Recti r = { { 0, 0 }, { 640, 480 } };
    Vec2i q = p;        // copy
    q.x = 100;
    assert(p.x == 3 && q.x == 100 && r.bottomRight.y == 480);
}

Result Main returns 1087

Structs are passed by reference

Primitives are passed by value, but a struct argument is always passed by reference, and nothing at the call site says so. A function that writes to a struct parameter changes the caller's variable.

Sexy
(struct Vec2i (Int32 x y))

(function Twice (Vec2i v) -> :
    (v.x = (v.x * 2))
    (v.y = (v.y * 2))
)

(function Main -> (Int32 result):
    (Vec2i p = 3 4)
    (Twice p)                         // p is now 6 8
    (result = p.x + p.y)
)
C++20
#include <cassert>

struct Vec2i { int x, y; };

void Twice(Vec2i& v)    // Sexy passes every struct like this, with no '&' to see
{
    v.x *= 2;
    v.y *= 2;
}

int main()
{
    Vec2i p = { 3, 4 };
    Twice(p);
    assert(p.x + p.y == 14);
}

Result Main returns 14

Out parameters as return values

A struct cannot be an output. Outputs can be primitives, interfaces or containers; the compiler calls structs "derived types".

Sexy
(struct Vec2i (Int32 x y))

(function Make -> (Vec2i v):
    (v.x = 3)
    (v.y = 4)
)

(function Main -> (Int32 result):
    (Vec2i p = Make)
    (result = p.x + p.y)
)

Error Output arguments cannot be of derived type. Error with output 'v' in 'Make' of 's3b-noout'.

The idiom instead is a trailing out struct parameter. When the last parameter is a struct, a declaration can call the function as if that parameter were its return value: (Vec2i q = Doubled p) passes q as result.

Sexy
(struct Vec2i (Int32 x y))

(function Doubled (const Vec2i p)(out Vec2i result) -> :
    (result.x = (p.x * 2))
    (result.y = (p.y * 2))
)

(function Main -> (Int32 result):
    (Vec2i p = 7 9)
    (Vec2i q = Doubled p)             // trailing out parameter used as a return value
    (result = q.x + q.y)
)
C++20
#include <cassert>

struct Vec2i { int x, y; };

Vec2i Doubled(const Vec2i& p)
{
    return { p.x * 2, p.y * 2 };
}

int main()
{
    Vec2i q = Doubled({ 7, 9 });
    assert(q.x + q.y == 32);
}

Result Main returns 32

const and out document intent but are not enforced on struct members in 1.7: a function can assign to a member of a const parameter, and the caller sees the change.

Sexy
(struct Vec2i (Int32 x y))

(function Reset (const Vec2i p) -> :
    (p.x = 0)
)

(function Main -> (Int32 result):
    (Vec2i p = 7 9)
    (Reset p)
    (result = p.x)
)

Result Main returns 0

Constructors

A struct may have a Construct method. When it does, the declaration passes the constructor arguments in parentheses instead of member values.

Sexy
(struct Kennel (Int32 dogId)(Int32 capacity))

(method Kennel.Construct (Int32 id):
    (this.dogId = id)
    (this.capacity = 4)
)

(function Main -> (Int32 result):
    (Kennel k (1808))
    (result = k.dogId + k.capacity)
)
C++20
#include <cassert>

struct Kennel
{
    int dogId;
    int capacity;
    explicit Kennel(int id): dogId(id), capacity(4) {}
};

int main()
{
    Kennel k(1808);
    assert(k.dogId + k.capacity == 1812);
}

Result Main returns 1812

Operators are functions with derived names

Sexy has no operator keyword. When it meets (a == b) on structs it calls a function whose name is built from the operation and the two type names: IsEqVec2iVec2i. != looks for IsNotEq…, and + looks for Add…, which writes into a third struct parameter. If the function is missing, the comparison is an error rather than a member-by-member default.

Sexy
(struct Vec2i (Int32 x y))

(function IsEqVec2iVec2i (Vec2i a)(Vec2i b) -> (Bool equal):
    (equal = ((a.x == b.x) and (a.y == b.y)))
)

(function Main -> (Int32 result):
    (Vec2i a = 1 2)
    (Vec2i b = 1 2)
    (if (a == b) (result = 1))
)

Result Main returns 1

(struct Vec2i (Int32 x y))

(function AddVec2iVec2i (Vec2i a)(Vec2i b)(Vec2i sum) -> :
    (sum.x = (a.x + b.x))
    (sum.y = (a.y + b.y))
)

(function Main -> (Int32 result):
    (Vec2i a = 1 2)
    (Vec2i b = 10 20)
    (Vec2i c = a + b)
    (result = c.x + c.y)

C++20
#include <cassert>

struct Vec2i
{
    int x, y;
    bool operator==(const Vec2i&) const = default;   // C++20: also gives !=
};

Vec2i operator+(const Vec2i& a, const Vec2i& b) { return { a.x + b.x, a.y + b.y }; }

int main()
{
    Vec2i a = { 1, 2 }, b = { 1, 2 }, c = { 10, 20 };
    assert(a == b);
    assert(a != c);
    Vec2i d = a + c;
    assert(d.x + d.y == 33);
}

Result Main returns 33
